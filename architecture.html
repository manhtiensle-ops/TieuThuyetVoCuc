Bảo mật · Security Layer

  • • JWT Access Token 15m + Refresh 30d
  • • bcrypt password hashing (cost=12)
  • • RBAC: Admin · Editor · VIP · Reader
  • • Rate limit Nginx (20r/s per IP)
  • • Brute-force guard (Redis counter)
  • • CSRF / XSS / SQLi protection
  • • HTTPS TLS 1.3 via Certbot
  • • Parameterized queries only

Database · Caching Layer

  • • PostgreSQL 16 (primary store)
  • • pgvector (semantic search chapters)
  • • Full-text search tsvector/tsquery
  • • Redis 7: chapter cache TTL 1h
  • • Redis: session store · rate limit
  • • Connection pool: asyncpg 20 conn
  • • Index: GIN (FTS) · B-tree (FK/slug)

Deploy · Infra · No Docker
